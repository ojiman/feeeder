# Feeeder

macOS 26.6以降向けのRSSリーダー。SwiftUI / AppKitで表示し、SwiftDataへ端末内保存します。アカウント・Backend・同期はありません。V1を実装中で、読書UXの性能改善と最終PdM受入が残っています。

## 起動

XcodeのSwiftツールチェーンで、プロジェクトルートから実行します。SwiftPMが固定版のSwiftSoup 2.13.9を解決します。

```sh
bash scripts/build-app.sh release
```

生成される `.build/Feeeder.app` をFinderから開いてください。未署名のローカル開発用アプリです。releaseの中間出力は `/private/tmp/feeeder-v1-release`、debugは `/private/tmp/rss-reader-build` に置きます。debug buildは引数を省略できます。

通常起動は空ライブラリから開始します。V1の保存先は `Application Support/Feeeder/Reader.store`。再起動しても購読・記事・既読日時・ノートを保持します。プロトタイプのデータ移行はありません。

合成デモは保存先と挿入を明示して起動します。

```sh
open '.build/Feeeder.app' --args --data-directory /private/tmp/feeeder-demo --seed-demo
```

`--data-directory <path>` は開発検証用の保存先指定です。合成デモの `.example` URLに実在ページはありません。実際の購読・記事・ノートをGitへ追加しないでください。

## 操作

- 左から購読元・記事一覧・本文の3カラム。外観はシステム追従・ライト・ダークから選べます。
- 左上の「＋」へRSS/Atom URLを入力して購読。手動XMLと合成サンプルも取り込めます。購読の右クリックで名前・1階層フォルダ・解除を操作します。
- 起動・復帰・稼働中30分ごとに更新し、ツールバーから手動更新できます。通信失敗でも保存済み記事を読み続けられます。
- 一覧にフォーカスして `j` / `k` で移動、`m` で既読／未読を切り替えます。一覧のスクロールでは既読にせず、本文またはRSS要約の実表示で初回既読日時を記録します。
- `b` で外部ブラウザ、`v` でアプリ内の原文、`Esc` で読書へ戻ります。原文閲覧は指定サイトへ通信し、アプリ内ブラウザはログイン状態を保存しません。
- 本文抽出はbest effortです。「フィード提供本文」「抽出本文・全文保証なし」「RSS要約のみ」を区別します。取得不可なら要約と原文リンクを残し、制限を回避する取得は行いません。
- 「振り返り」から週ノートを編集できます。前週を先に表示し、現在週は下書き。同じ週に複数ノートを作れます。初回ノート作成時の期間・Timezoneを保存し、以後も同じ範囲を使います。
- 記事本文・RSS要約は初期30日、Settingsで7 / 30 / 90 / 365日へ変更できます。未読は初回受信、既読は初回既読が起算点。保持短縮・本文一括削除は対象を確認して実行します。ノートと採用済み出典タイトル・URLは自動削除しません。

## Claude Desktop連携

記事または週ノートから「AI入力を確認」を開きます。出力言語と出典を選び、省略のない全文・カバー範囲・出典URLをレビューして「Claudeで開く」を操作します。

確認対象は **Claude Desktop 2.19675.0 / Pro / Cowork**。通常Chatへの自動添付、他版・他プランは未検証です。アプリは短い依頼文とTXTのパスを起動リンクへ渡し、記事本文はTXT内に保持します。

Claude側の **Attach確認** と **本人による送信** が必要です。送信後に別のフォルダ許可が出る場合があります。この許可はフォルダ内の読取り・変更を可能にし、cloudで使われるファイルは端末を離れます。Feeederは生成パッケージと管理metadataだけを専用フォルダに置きます。リンク由来の依頼文に注意表示が出る場合もあります。起動成功は、添付完了・送信・読取り成功を意味しません。

取消・起動失敗時は同じレビュー内容で再試行でき、全文コピー・TXT書き出しも使えます。制限時は1MiB以下のUTF-8分割ファイルを書き出せます。この分割サイズはClaudeの対応上限を示す値ではありません。

アプリ管理コピーは生成から24時間と元本文の期限の早い方まで保持します。保持短縮・本文削除にも同期します。本人が指定した書き出し先と、Claude側に渡った内容はこの削除の対象外です。返答を読んでノートへ貼り付け、出典を採用する操作は本人が行います。自動送信・返答の自動書込みはありません。

## 検証と仕様

```sh
swift test --scratch-path /private/tmp/feeeder-v1-build
```

テストは合成RSS/HTMLと一時DBを使います。[PRD](docs/specification.md)、[Architecture](docs/architecture.md)、[実機受入記録](docs/verification/2026-10-05-v1-acceptance.md)に仕様・検証結果・未確認事項を記録しています。macOS 26.6での実機動作、Reeder Classicを参考にした操作感のPdM判断、V1全体の受入は未完了です。

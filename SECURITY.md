# Security Policy

## Reporting a Vulnerability

Please report potential security vulnerabilities through this
repository's Security → Advisories → Report a vulnerability.

Do not disclose vulnerability details in public issues.

Include a description of the issue, steps to reproduce it,
the affected version or commit, and the potential impact.
Use synthetic data where possible. Do not include credentials
or personal data.

This project is maintained by an individual. Reports are reviewed
on a best-effort basis, without guaranteed response or fix times.
We will discuss findings and next steps through the private report.

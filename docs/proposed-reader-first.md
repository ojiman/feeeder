## 変更する順序

仕様§4.5とAGENTS.mdに、以下の「対話開発の初版」を追加する。無人workerの全受入が完了する前でも、この対話セッションの親が、以下の範囲でアプリ本体を実装・ローカルcommitできるようにする。

- 最初の成果物: Macで起動する3カラム、ダークモード、合成記事の表示、j/k・既読・likeとローカル保存。追加依存なし、外部通信なし、Keychainアクセスなし。
- 次の成果物: RSS/Atom解析、購読管理、b/v/Esc。その後に実フィード取得と本文抽出を追加する。公開fixture取得など、既存の内容確認が必要な操作はその段階で扱う。
- 本体ソースはプロジェクト内、破棄可能なビルド出力は専用領域または共有`/private/tmp`。ビルド・テストに必要な権限は具体的なコマンドで扱い、ホーム全体やネットワークの包括許可を増やさない。
- 実キー・本人の購読履歴・サイトログインは使わない。Keychain試験は停止を維持し、BYOK着手前に検証方法を決める。
- GitHub push、CI、署名・配布は後回し。初版は開発用ビルドとして扱い、ストア品質の完成は主張しない。

## 維持することと、受け入れる制約

ハーネス章とF/H受入条件は残す。未確認項目やKeychainのBLOCKEDは合格へ書き換えず、「対話開発の初版」に限って着手・ローカル保存の前提から外す。無人worker運用と公開前には、それぞれの前提条件を満たす。

この対話セッション自体の広いツール・読取権限が狭くなるわけではない。個人データを扱わない作業方針と、完全な実行時隔離は区別する。この制約を受け入れて、親が小さな差分を作り、テスト結果と操作結果をユーザーが確認する進め方にする。隔離未検証のsubagentを独立検証者として起動したとは扱わない。

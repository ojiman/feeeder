# 0004 Dogfooding改訂: キー操作・スクラップ・週候補

- 状態: 有効（承認済み内容の転記。承認根拠は出典のPR）。ただし日次・週ノート、スクラップ（`n`）、週候補、日次ノートの日とタイムゾーンの固定に関する部分は、[0008](0008-theme-centered-notes.md)（PR #21で承認）に置換済み
- 日付: 2026-10-07（PR #6のマージ、日本時間）
- 決定者: 本人（PdM）

## 背景

V1のDogfoodingで、既読履歴だけでは関心を絞りにくいことから、Star・日次スクラップ・3カラムの役割を見直した。仕様はPR #6で承認された。

## 決定

本人との合意事項:

- `n` は現在の記事を当日の既定ノートへスクラップする。`j/k` は記事の移動、`s` はStarの付け外し。
- スクラップの保存内容は、記事タイトル・原文URL・保存時点で保持しているRSS要約・編集可能な本人のメモ。取得本文の全文は複製しない。
- スクラップ済みのRSS要約は、元記事の期限削除に連鎖させない。
- 任意の日付・期間・ノートへのスクラップは将来候補とし、V1では当日の既定ノートだけ。

PR #6のPdM承認で確定した内容:

- 週の振り返りの初期候補は、Starの付与日時とスクラップの保存日時を基準にする。既読履歴は別表示で選べる。
- 日次ノートと週ノートを併存させる。日次ノートの日とタイムゾーンも初回作成時に固定し、週の固定期間とは別に保存する。
- Feeds / Notesで共通の3カラム構成を使う。
- フォルダ操作（1階層、購読の割当・移動、名前変更、記事の集約）と、Favicon／記事画像の扱い。

## 影響

- キー割当や保存内容を変える提案は、この決定を覆す変更として扱い、利用者の確認を取る。
- 現行の挙動は docs/specification.md §3.1・§3.2・§3.3に記す。
- 以前から残る実機受入項目は、この決定の対象外で、PASSに変えない。

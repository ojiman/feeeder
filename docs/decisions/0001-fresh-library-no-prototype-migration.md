# 0001 V1は空ライブラリから始める

- 状態: 有効
- 日付: 2026-10-05
- 決定者: 本人（PdM）

## 背景

プロトタイプから引き継ぐ利用データがないことを、利用者が確認した。

## 決定

V1は新しい空のライブラリから開始する。プロトタイプからのデータ移行、互換モデル、日時補完は対象外とする。

## 影響

- 旧プロトタイプ用のモデルや、初期化による復帰処理を追加しない。
- 配布済みのV1以降のデータ互換は、別の決定で扱う（[0003](0003-beta-data-compatibility.md)）。

# 0002 実装者は同時に1名

- 状態: 有効
- 日付: 2026-10-04（確認できた最古の出典はPR #1のマージ日）
- 決定者: 本人（PdM）

## 背景

エージェントに実装を任せるハーネスを、V1の範囲で簡素にする必要があった。実行時の境界はエージェントとOSの設定で決まり、指示文だけでは強制できない。

## 決定

- 通常作業は、利用者が会話と差分を確認できる対話型開発とし、実装者は同時に1名とする。
- 専用の無人worker、常駐broker、VM群、役割別の権限サーバーは作らない。
- レビュー者は、固定したcommitを読む。同じ作業コピーを書ける状態を「独立した読取専用検証」とは呼ばない。

## 影響

- 無人実行を始める場合は、隔離環境と否定試験を用意してから別途判断する。
- 指示文だけで境界を保証したことにしない（ハーネスの合格条件は architecture.md §4.5）。

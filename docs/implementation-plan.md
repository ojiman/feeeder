# 実装順序

2026-09-06: 仕様承認を受けて開始。仕様のF/H受入条件は変更しない。

1. **H0 — ハーネスの準備**: role別ファイル境界、環境変数、通信、子プロセスの否定テストを、非秘密の専用作業領域で作成・実行する。結果は部分試験として保存。実効ポリシー、ツール公開範囲、Keychain IPC、基準版の保護まで揃ってからユーザーが採用する。
2. **F1 — 最初の読書経路**: 依存なしのXcodeプロジェクト、SwiftDataモデル、RSS/Atom解析、3カラム、fixtureによる起動と保存。j/k/h/l、b/v/Esc、既読・likeを実装。F-01〜04/06を段階的に検証。
3. **F2 — 本文取得**: 固定依存と公開fixtureをユーザーが取得した後、隔離WebView、サイト別補正、世代管理、like本文保存を実装。F-05/06を検証。
4. **F3 — 要約**: サイト・期間フィルタ、snapshot、チャンク、出典検証、Keychain、同意、offline API応答を実装。F-07〜09。レビュー済みアプリでユーザーが実APIスモーク。
5. **F4 — 配布**: Universal、App Sandbox、署名・実機操作確認後、ユーザーがDeveloper Program登録と公開操作。F-10。

各単位は実装停止 → 固定snapshot → 独立検証 → TechLead/PdMレビュー → 統合。個々の関数にレビューを増設しない。ストア公開や実キー待ちをアプリ動作の合否と混同しない。
